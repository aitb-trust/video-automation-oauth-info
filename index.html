개인용 영상 관리 도구

Video Automation

운영자가 자신의 YouTube 채널을 관리하기 위해 사용하는 로컬 자동화 도구입니다. 공개 영상 검색, 편집 영상의 비공개 업로드, 다음 실행 회차의 공개 전환을 지원합니다.

사용 방법과 데이터 접근

Google OAuth로 운영자가 직접 승인한 채널에 연결합니다. 채널 ID와 영상 정보를 확인하고, 검수한 영상 파일 및 제목·설명을 YouTube에 전송합니다. 새 영상은 비공개로 올리고 다음 예약 실행에서 이전 회차 영상을 공개합니다.

채널 정보, 영상 ID, 제목·설명, 처리·공개 상태와 작업 기록을 사용합니다. 인증 정보는 Windows 자격 증명 관리자에 보관합니다. 이 안내 사이트에는 로그인, 영상 업로드, 인증 정보 수집 기능이 없습니다.

이용 범위

운영자의 개인용 도구이며 일반 사용자를 대상으로 계정 가입이나 영상 처리 서비스를 제공하지 않습니다. Google 또는 YouTube의 공식 서비스가 아닙니다.
